# Faunira Website

Frontend for **Faunira: Real Potency Formulations**, a veterinary and poultry healthcare company.

Built with plain **HTML + CSS + JavaScript** (no build step).

## View locally
Open `index.html` in a browser, or run a local server:

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```

## Structure
```
index.html              Home page
assets/css/style.css    All styles (light + dark theme tokens at the top)
assets/js/main.js       Theme toggle, menu, animations, enquiry form (contact CONFIG at the top)
assets/img/             Logo and (sample) product images
SRP.md                  Checklist of sample content to replace with real details
```
